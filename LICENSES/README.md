# Included license texts

The project license is the complete GNU AGPL version 3 text in ../LICENSE.
AGPL-3.0.txt is the same text, retrieved from Ultralytics 8.4.38's LICENSE.
Upstream copyright holders retain their rights; see ../NOTICE.md.

`scripts/fetch-licenses.mjs` records the source URLs used for the upstream license
copies in this directory. Texts were retrieved on October 5, 2026. The script is a
maintainer utility; normal builds use these committed copies without networking.
DEPENDENCIES.txt is generated by scripts/dependency-notices.mjs from installed,
locked dependencies during build. It preserves their package license texts.

CC-BY-2.0.html is Creative Commons' official legal-code page; fixture attribution
is recorded in ../tests/fixtures/README.md. ONNX-Runtime-ThirdPartyNotices.txt
is the upstream notice, retained alongside its MIT license. The broader upstream
notice includes components that may not be part of the specific WASM build.

Do not edit third-party license grants to make them match the project license.
Retain the separate texts and the attribution/modification notices.
